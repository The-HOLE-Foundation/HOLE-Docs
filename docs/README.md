## 📝 Documentation Standards

All documentation in this repository follows these principles:

- **Clear**: Easy to understand for the target audience
- **Complete**: Covers all necessary information
- **Current**: Kept up-to-date with project changes
- **Consistent**: Follows standard formatting and structure
- **Correct**: Technically accurate and tested

## 🔧 Using Context7

This repository is configured for Context7, an MCP server for enhanced documentation navigation. The `context7.json` file in the root directory defines the documentation structure.
